Pill-shaped brand button. Use `primary` (lime) for the single main CTA on a screen, `secondary` (outline black) for supporting actions, `dark` on light contexts that need contrast (e.g. hero over photo).

```jsx
<Button variant="primary" size="lg">Compra HT</Button>
<Button variant="secondary">Ver facturas</Button>
```
Never two primary lime buttons on the same view.

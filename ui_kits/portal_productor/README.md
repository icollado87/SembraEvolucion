# Portal Productor — UI kit (mobile)

Mobile-first recreation of the four core Portal Productor flows called out in the PRD's Sprint 1:

- **HomeMobile** — hero photo + stacked lime metric cards (CEBADA / TRIGO / SOJA)
- **CompraHT** — vertical stepper with crop selector and tech options
- **Licencias** — filterable table with unified status badges
- **CuentaGranaria** — crop + campaña + plataforma selectors, with proper empty state

Open `index.html` for the click-through. Navigation is faked (state-only, no routing). Copy is drawn from the real screens; images are placeholders — swap for the real hero art when available.
